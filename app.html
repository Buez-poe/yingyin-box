遇到问题？看这里
扫不到新集：目录列表可能被 OpenList 缓存（默认约 30 分钟）。勾选"强制刷新目录列表"后重试，或到 OpenList 网页手动刷新该目录。
连接失败：先点「连接自检」。若提示 CORS / Failed to fetch，需给 OpenList 反代加跨域响应头，或把本页放到与 OpenList 同域的静态目录访问。
整部重做：才可全量替换旧的 strm 文件；只加新集时别覆盖已有的。
播放失败：常见原因不仅是签名过期——还包括管理员 token 轮换、OpenList 地址或端口变更、视频路径改名、媒体服务器无法访问播放地址。请先核对 strm 里的那一行 URL。
内网 http 连不上：在线 https 版连 http://192.168.x.x 这类内网 OpenList 会被浏览器按「混合内容」阻断，请下载本地 HTML 版再用；同时给 OpenList 配好 CORS 白名单。
风控提醒：302 直连 + 异地播放会把客户端 IP 暴露给网盘，多人/异地使用有风控风险；长期多人建议用 NAS 中转或自建反代。

准备就绪。先选媒体库目录，再点「扫描媒体库（剧集 + 电影）」。
刮削后还是没封面？Jellyfin / Emby 必做设置
1. 让服务器优先读本地 NFO
Jellyfin：控制台 → 媒体库 → 编辑该库 →「元数据读取器」把 Nfo 移到第一位（或只留 Nfo）。
Emby：媒体库 → 编辑 →「元数据」→ 勾选 Nfo 并置顶。

2. 元数据语言设成 简体中文（否则 TMDB 返回英文，中文剧名容易匹配不上）。

3. 图像抓取器勾选「本地图片」：Jellyfin 控制台 → 媒体库 → 图像抓取器 → Local Images；Emby 同理。本工具会把 poster.jpg / fanart.jpg 直接写在剧目录（季海报为 season01-poster.jpg）。

4. 刷新已有条目：对剧集点「刷新元数据」→ 勾选「替换所有元数据（含图像）」。只扫库不会重读 NFO。

5. 目录结构必须对：剧名/tvshow.nfo、剧名/poster.jpg、剧名/Season 01/剧名 S01E01.strm、剧名/Season 01/剧名 S01E01.nfo。本工具按此结构写入；电影是 片名/movie.nfo。

没有 TMDB Key 也能用：取消勾选联网项，只写 NFO + 本地封面，服务器完全不联网也能显示剧名、集号、封面。

梵想云 / 其他媒体中心：只要支持 NFO（Kodi 规范），同样读取本工具写的 tvshow.nfo / 集 NFO；不支持的，至少本地 poster.jpg 会被当封面。

字幕说明 / 什么时候用
本工具打包的是外挂字幕（独立 .srt/.ass/.ssa/.sub 文件），不是从视频里提取字幕。
通常内嵌字幕能被 Jellyfin / Emby 读出；只有当内嵌字幕读不出来（格式特殊、图形字幕等）时，才需要把现成的外挂字幕放到视频旁边。
默认"与视频同名"会把字幕改成视频的名字、自动去掉语言后缀，多语言重名时保留 zh/en 标记避免覆盖。

离线冻结承诺：已下载的离线 HTML 永久可用、永不回连、永不因版本更新失效；在线版可能迭代，本地那份归你。若未来增加付费服务，已发布版本功能不锁。
数据边界：没有接收视频 / Key / OpenList 凭据的业务后端。视频与目录只在浏览器和你的 OpenList 之间流动；TMDB Key 只发给 TMDB；OpenList 密码只在当前页面内存里，会发给你自己的 OpenList。唯一例外是官网底部反馈表单：称呼与留言经转发接口送给作者，不接触视频、目录、Key 或 OpenList 凭据，提交前可在 DevTools → Network 看到完整 payload。
威胁模型一页纸（凭据从哪来 / 存哪 / 活多久 / 怎么清）
TMDB Key / Token：你手动填入；默认 localStorage（同源可读，风险来自浏览器扩展与共用电脑），勾选会话模式后只在内存；活到你清除或刷新；点「清除 TMDB Key」或「清除全部本地数据」即可。
OpenList 账号密码：你手动填入；只在当前页面内存，不写配置、不进 zip；刷新即失效；关闭页面即可。
OpenList token：登录后由 OpenList 返回；只在内存；刷新或改地址后失效；重新连接即可。
生成出的 strm：只含 OpenList 的 /d/ 路径模板与可选签名，不含账号密码；会写进 zip，请勿把含 sign= / token= / pwd= 的包外传（工具会在生成时提示）。
manifest.json：含路径、标题、年份、TMDB ID、封面来源，不含凭据；随 zip 走，用于下次 diff。
