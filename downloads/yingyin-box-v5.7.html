播放失败：常见原因不仅是签名过期——还包括管理员 token 轮换、OpenList 地址或端口变更、视频路径改名、媒体服务器无法访问播放地址。请先核对 strm 里的那一行 URL。

刮削后还是没封面？Jellyfin / Emby 必做设置
1. 让服务器优先读本地 NFO
Jellyfin：控制台 → 媒体库 → 编辑该库 →「元数据读取器」把 Nfo 移到第一位（或只留 Nfo）。
Emby：媒体库 → 编辑 →「元数据」→ 勾选 Nfo 并置顶。

2. 元数据语言设成 简体中文（否则 TMDB 返回英文，中文剧名容易匹配不上）。

3. 图像抓取器勾选「本地图片」：Jellyfin 控制台 → 媒体库 → 图像抓取器 → Local Images；Emby 同理。本工具会把 poster.jpg / fanart.jpg 直接写在剧目录（季海报为 season01-poster.jpg）。

4. 刷新已有条目：对剧集点「刷新元数据」→ 勾选「替换所有元数据（含图像）」。只扫库不会重读 NFO。

5. 目录结构必须对：剧名/tvshow.nfo、剧名/poster.jpg、剧名/Season 01/剧名 S01E01.strm、剧名/Season 01/剧名 S01E01.nfo。本工具按此结构写入；电影是 片名/movie.nfo。

没有 TMDB Key 也能用：取消勾选联网项，只写 NFO + 本地封面，服务器完全不联网也能显示剧名、集号、封面。

梵想云 / 其他媒体中心：只要支持 NFO（Kodi 规范），同样读取本工具写的 tvshow.nfo / 集 NFO；不支持的，至少本地 poster.jpg 会被当封面。

字幕说明 / 什么时候用
本工具打包的是外挂字幕（独立 .srt/.ass/.ssa/.sub 文件），不是从视频里提取字幕。
通常内嵌字幕能被 Jellyfin / Emby 读出；只有当内嵌字幕读不出来（格式特殊、图形字幕等）时，才需要把现成的外挂字幕放到视频旁边。
默认"与视频同名"会把字幕改成视频的名字、自动去掉语言后缀，多语言重名时保留 zh/en 标记避免覆盖。
