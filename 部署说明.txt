以后怎么更新
------------
方法一：命令行（推荐，最快）
1. 在本目录打开 PowerShell。
2. 确认本机已设置 CLOUDFLARE_API_TOKEN 和 CLOUDFLARE_ACCOUNT_ID。
3. 执行：
   npx wrangler pages deploy . --project-name yingyin-box-site --branch main
4. 等命令输出 Deployment complete，打开上面的网址刷新即可。

方法二：网页上传
1. 打开 https://dash.cloudflare.com/
2. 进入 Workers & Pages → yingyin-box-site。
3. 点“创建新部署”，选“上传静态文件”。
4. 把本目录里的 index.html、downloads 文件夹等一起拖进去。
5. 点部署，等完成。


文件怎么放
----------
index.html                        首页，必须放在最外层
downloads/yingyin-box-v5.7.html   网页版工具
downloads/yingyin-box-v5.7.zip    完整包
README.md                         项目说明
LICENSE                           MIT 许可证
部署说明.txt                      本文件

注意：downloads 文件夹要整个上传，不能只传 index.html。


改作者信息
----------
打开 index.html，拉到最底部，找到 SITE_CONFIG：
  author      作者昵称
  email       想公开的邮箱，留空就不显示
  giteeRepo   源码仓库地址

改完保存，再按上面的方法重新部署一次。


安全提醒
--------
- Cloudflare API Token 只放在本机环境变量或临时文件，不要写进网页、README、Git 仓库。
- 本站没有后端，不接收视频，不保存 TMDB Key。
