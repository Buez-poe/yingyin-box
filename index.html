为什么可以放心

它不碰你的视频，也不藏你的密码。

这不是一句口号，而是这个工具的工作方式。下面四件事，你都可以自己验证。

视频文件留在原地

工具只读取文件名和目录结构，用来生成 .strm 播放文件。视频本身不会上传给作者，也不会经过任何中间服务器。

TMDB Key 只存本机

Key 只保存在当前浏览器的 localStorage，官网只有一个邮件表单接口，收不到 Key。输入框下方有 “清除 TMDB Key”，点一下就能清空。

NAS 密码不保存

OpenList 的用户名和密码只在当前页面内存里使用，关掉页面就没了。密码不会被写进配置文件，也不会被作者看到。

没有广告和统计

页面不加载第三方脚本，不接统计工具，不弹广告。下载也不需要关注公众号、加群或注册账号。

三步就完成

不用研究选项，默认已经帮你处理好了。

以前要勾五六个复选框，现在只保留三步。NFO、海报、季海报和本地封面兜底，默认自动完成。

01

选择视频目录

选云盘里的剧集或电影文件夹。工具会自己识别是剧还是电影，并读取集号结构。

02

填媒体库位置

例如 /media/tv 或 /media/movies。这是最后 zip 里目录的落点，不是上传地址。

03

点开始生成

生成播放文件、影片信息和封面，最后打成一个 zip。解压后整个文件夹放进媒体库即可。

第二周才见真章。 加集、改名、删片时不用整库重做：导入上次 manifest，或直接从媒体库根目录读；先看差异预检，可逐条改片名 / 年份 / 季 / 集、勾选跳过。默认只新增、不覆盖，手工换过的海报和 NFO 原样保留；只有显式打开「覆盖模式」并二次确认，才会重写已有文件。
没有 TMDB Key 也能用。 只生成基础影片信息和本地封面；填了 Key 才会多出简介、评分和官方海报。第一次用，建议先不填 Key 试一遍。

安全说明

你的东西，去了哪里？

把数据流向讲清楚，比写“绝对安全”更有用。下面每一行，都可以在浏览器里自己核对。

视频文件

留在你的电脑或 NAS。工具只读取目录和文件名，生成 .strm 播放文件，不上传视频。

片名

会发给 TMDB 查简介、评分和官方海报。这是查资料必需的一步，但只发片名，不发视频。

TMDB Key

默认只存当前浏览器 localStorage（同源可读，风险来自浏览器扩展与共用电脑）；可勾选「仅本次会话」只留内存；可一键清除；导出配置时自动去掉 Key / Token。

OpenList 密码

只在当前页面内存里使用，关掉页面就没了；会发给你自己填的 OpenList，不写入配置，不保存到本机。

TMDB Key / Token：你手动填入 → 默认 localStorage → 活到你清除或刷新 → 点「清除 TMDB Key」或「清除全部本地数据」。勾选会话模式后只在内存。
OpenList 账号密码：你手动填入 → 只在当前页面内存 → 刷新即失效 → 关闭页面即可。
OpenList token：登录后由 OpenList 返回 → 只在内存 → 刷新或改地址后失效 → 重新连接即可。
生成出的 strm：只含 /d/ 路径模板与可选签名，不含账号密码 → 会写进 zip → 含 sign= / token= / pwd= 的包请勿外传。
manifest.json：含路径、标题、年份、TMDB ID、封面来源，不含凭据 → 随 zip 走，自动上传时写回媒体库根目录 → 下次直读或导入，用于只新增 / 变化重写的 diff。

常见问题

小白最常问的几件事。

如果下面没有你的问题，去代码仓库提 Issue（需要登录 Gitee），或 发邮件给作者。

会不会上传我的视频？

不会。 工具只读取目录和文件名，生成播放文件；视频本身不上传，也不经过作者的服务器。

没有 TMDB Key 能用吗？

能用。 会生成基础影片信息和本地标题封面，Jellyfin / Emby 照样能识别剧集结构和集号；只是没有简介、评分和官方海报。

Key 会被作者看到吗？

不会。 Key 只保存在你的浏览器里；反馈表单只接收称呼和留言，不接收视频、目录、Key 或 OpenList 凭据。你可以随时点“清除 TMDB Key”或“清除全部本地数据”，也可以勾选“仅本次会话”让它不落盘。

为什么需要 TMDB？

TMDB 是一个公开的影视资料库。工具把片名发过去，换回简介、评分、演职员和官方海报。不填 Key 也能用，只是资料会少一些。

支持 Jellyfin / Emby 吗？

支持。 生成的是它们能识别的 .strm、NFO 和图片目录结构。这里是兼容说明，不代表官方合作或认证。

NAS 密码会被保存吗？

不会。 OpenList 的密码只在当前页面内存里使用，关掉页面就没了；配置文件也不会写入密码。

支持哪些浏览器？

首屏会直接显示当前浏览器能力：支持直写目录 / 将退回 zip / 只能 zip 下载。Safari / Firefox 不支持直接写入本地文件夹时，会自动退回 zip 下载；功能还在，只是少一个直写入口。内网 http 的 OpenList 请用下载后的本地版，在线 https 版会被浏览器按混合内容阻断。

为什么浏览器提示“可能有风险”？

单文件 HTML 从网上下载时，部分浏览器会做保守提示，这不等于病毒结论。你可以先查看源码、用杀毒软件扫描，或在不重要的备用机试用。

收费吗？以后会收费吗？

当前免费。 没有强制关注、加群或账号。以后如果增加付费服务，会提前说明，不会突然把现有功能锁掉。

怎么更新？第二周加集怎么办？

离线冻结：已下载的离线 HTML 永久可用、永不回连、永不因版本更新失效；在线版可能迭代，本地那份归你。加集时不用整库重做：导入上次 zip 里的 manifest.json，或开启自动上传后直接从媒体库根目录读；工具先出差异预检，列出新增、源文件变化、未变化跳过和旧条目（默认不删），片名 / 年份 / 季 / 集可逐条改、可勾选跳过，确认后才生成。默认只新增、不覆盖，手工放的海报 / NFO 原样保留；要整部重做才打开「覆盖模式」，它会二次确认。

会把我的播放链接或签名传出去吗？

工具只生成你媒体库里的 strm；链接里若含 sign= / token= / pwd=，页面会提示，并可在高级设置里选择不写签名、只写 /d/ 路径模板。含鉴权参数的 zip 请勿外传。

多人 / 异地播放有风控风险吗？

有。302 直连 + 异地播放会把客户端 IP 暴露给网盘，多人或异地使用可能触发网盘风控；长期多人建议用 NAS 中转或自建反代。

片源版权和官方合作怎么算？

工具不含任何片源，片源版权与网盘服务条款由使用者自行负责。Jellyfin / Emby 为各自项目所有；本工具只说明兼容性，不代表官方合作或认证。
